# Frontend

## Descrição

Esta pasta contém a aplicação web do Conecta Marketplace.

O frontend será responsável pela interface visual utilizada pelos clientes, prestadores e administradores da plataforma.

A aplicação deverá proporcionar uma experiência simples, intuitiva, responsiva e acessível, permitindo que os usuários realizem todas as principais operações da plataforma.

## Principais responsabilidades

O frontend deverá permitir:

- Cadastro de usuários;
- Login e logout;
- Recuperação de acesso;
- Gerenciamento do perfil;
- Busca de serviços;
- Pesquisa de profissionais;
- Visualização de perfis;
- Visualização de avaliações;
- Criação de solicitações;
- Recebimento e análise de propostas;
- Aceitação ou recusa de propostas;
- Agendamento de serviços;
- Visualização do histórico;
- Comunicação entre cliente e prestador;
- Avaliação dos serviços;
- Gerenciamento da disponibilidade do prestador;
- Visualização de notificações.

## Perfis de utilização

A interface deverá considerar diferentes experiências para:

### Cliente

Usuário que procura e contrata serviços.

### Prestador

Usuário que oferece seus serviços e recebe oportunidades de trabalho.

### Administrador

Usuário responsável pelo gerenciamento e moderação da plataforma.

## Tecnologias

A tecnologia do frontend será definida durante a fase de implementação.

A possibilidade inicialmente considerada é:

- React;
- TypeScript;
- HTML;
- CSS.

## Integração

O frontend consumirá a API disponibilizada pelo backend.

A comunicação deverá utilizar APIs REST e mecanismos adequados de autenticação e autorização.

## Objetivo

Criar uma interface moderna e intuitiva que simplifique o processo de encontrar, contratar e prestar serviços.
