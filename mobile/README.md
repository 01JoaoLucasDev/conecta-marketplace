# Mobile

## Descrição

Esta pasta será destinada ao desenvolvimento futuro do aplicativo mobile do Conecta Marketplace.

O aplicativo terá como objetivo oferecer uma experiência otimizada para dispositivos móveis, permitindo que clientes e prestadores utilizem a plataforma diretamente pelo smartphone.

## Funcionalidades previstas

O aplicativo poderá oferecer:

- Cadastro e login;
- Gerenciamento de perfil;
- Busca de serviços;
- Localização de profissionais;
- Geolocalização;
- Solicitação de serviços;
- Recebimento de propostas;
- Agendamento;
- Chat;
- Notificações push;
- Avaliações;
- Histórico de serviços;
- Gerenciamento de disponibilidade;
- Acompanhamento de serviços.

## Recursos específicos para dispositivos móveis

O aplicativo poderá utilizar recursos nativos do dispositivo, como:

- GPS;
- Notificações push;
- Câmera;
- Galeria de imagens;
- Permissões de localização.

## Tecnologias

A tecnologia mobile será definida posteriormente.

Possíveis alternativas:

- React Native;
- Flutter.

## Integração

O aplicativo utilizará a mesma API disponibilizada pelo backend da plataforma.

## Status

O desenvolvimento mobile não faz parte da primeira versão do sistema e será implementado posteriormente.

## Objetivo

Disponibilizar uma experiência móvel completa e conveniente para clientes e prestadores.
