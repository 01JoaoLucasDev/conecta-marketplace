# Conecta Marketplace

Marketplace de serviços locais que conecta clientes a profissionais com base em habilidades, localização, disponibilidade e reputação.

## Objetivo

Facilitar a contratação de serviços e ampliar as oportunidades de trabalho para profissionais autônomos.

## Status

Em desenvolvimento.

## Tecnologias

As tecnologias serão definidas durante o desenvolvimento do projeto.
