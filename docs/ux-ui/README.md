# UX/UI

## Descrição

Esta pasta contém a documentação relacionada à experiência do usuário (UX) e à interface visual (UI) do Conecta Marketplace.

O objetivo é planejar e documentar a experiência dos diferentes usuários antes e durante o desenvolvimento das interfaces.

## UX — User Experience

A documentação de UX poderá incluir:

- Personas;
- Jornada do usuário;
- Fluxos de navegação;
- Mapeamento de problemas;
- Arquitetura da informação;
- Wireframes;
- Testes de usabilidade.

## UI — User Interface

A documentação de UI poderá incluir:

- Identidade visual;
- Paleta de cores;
- Tipografia;
- Componentes;
- Botões;
- Formulários;
- Cards;
- Ícones;
- Espaçamentos;
- Layouts;
- Design System.

## Principais usuários

A experiência deverá considerar principalmente:

### Cliente

Deve conseguir encontrar e contratar um profissional de maneira simples e segura.

### Prestador

Deve conseguir apresentar suas habilidades, disponibilidade e experiência e encontrar oportunidades de trabalho.

### Administrador

Deve possuir ferramentas adequadas para gerenciamento e moderação da plataforma.

## Objetivo

Criar uma experiência simples, intuitiva, acessível e consistente em todas as interfaces do sistema.
