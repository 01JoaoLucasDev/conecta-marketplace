# Arquitetura

## Descrição

Esta pasta contém a documentação da arquitetura técnica do Conecta Marketplace.

Aqui serão registradas as decisões relacionadas à estrutura da aplicação, comunicação entre componentes e tecnologias utilizadas.

## Conteúdo

Esta pasta poderá conter:

- Diagramas de arquitetura;
- Diagramas de componentes;
- Diagramas de sequência;
- Diagramas de implantação;
- Decisões arquiteturais;
- Padrões utilizados;
- Integrações externas;
- Estrutura dos módulos.

## Arquitetura inicial

O projeto será inicialmente desenvolvido utilizando uma arquitetura organizada em camadas, com possibilidade de evolução conforme as necessidades da aplicação.

O backend será responsável pelas regras de negócio e disponibilização da API.

O frontend será responsável pela interface do usuário.

O banco de dados será responsável pela persistência das informações.

## Decisões técnicas

As principais decisões arquiteturais deverão ser documentadas para que seja possível compreender:

- Por que determinada tecnologia foi escolhida;
- Quais alternativas foram avaliadas;
- Quais problemas foram identificados;
- Quais consequências a decisão possui.

## Objetivo

Manter uma visão clara da estrutura técnica do sistema e facilitar sua manutenção e evolução.
