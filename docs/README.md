# Documentação

## Descrição

Esta pasta contém toda a documentação técnica e funcional do Conecta Marketplace.

O objetivo é registrar as decisões, requisitos, regras, arquitetura, modelos e demais informações necessárias para compreender e evoluir o sistema.

A documentação deverá acompanhar a evolução do projeto.

## Organização

A documentação está dividida em diferentes áreas:

- Requisitos;
- Regras de negócio;
- Casos de uso;
- Arquitetura;
- Banco de dados;
- UX/UI.

## Objetivo

Manter as informações do projeto centralizadas, organizadas e atualizadas, permitindo que qualquer pessoa envolvida no desenvolvimento consiga compreender o funcionamento da plataforma.

## Princípio

Antes de implementar funcionalidades importantes, seus requisitos e comportamentos deverão ser documentados.

A documentação deverá ser atualizada sempre que houver mudanças relevantes no sistema.
