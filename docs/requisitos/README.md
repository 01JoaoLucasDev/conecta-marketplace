# Requisitos

## Descrição

Esta pasta contém os requisitos funcionais e não funcionais do Conecta Marketplace.

Os requisitos descrevem o que o sistema deverá fazer e quais características de qualidade deverá possuir.

## Requisitos funcionais

Os requisitos funcionais representam as funcionalidades que o sistema deverá oferecer.

Exemplos:

- Cadastro de usuário;
- Login;
- Cadastro de prestador;
- Cadastro de habilidades;
- Busca de serviços;
- Busca de profissionais;
- Solicitação de serviços;
- Envio de propostas;
- Agendamento;
- Avaliação;
- Sistema de mensagens.

## Requisitos não funcionais

Os requisitos não funcionais representam características relacionadas à qualidade e ao funcionamento da aplicação.

Exemplos:

- Segurança;
- Performance;
- Disponibilidade;
- Escalabilidade;
- Usabilidade;
- Acessibilidade;
- Manutenibilidade;
- Privacidade;
- Compatibilidade.

## Organização

Cada requisito deverá possuir uma identificação única.

Exemplo:

RF-001 - Cadastro de usuário

RF-002 - Login

RF-003 - Cadastro de prestador

RNF-001 - Segurança

RNF-002 - Performance

## Objetivo

Criar uma especificação clara do comportamento esperado do sistema antes e durante a implementação.
