# Banco de Dados — Documentação

## Descrição

Esta pasta contém a documentação da modelagem de dados do Conecta Marketplace.

O objetivo é apresentar de forma visual e conceitual como as informações da plataforma serão organizadas e relacionadas.

## Conteúdo

Poderão ser armazenados nesta pasta:

- Modelo conceitual;
- Modelo lógico;
- Modelo físico;
- Diagrama Entidade-Relacionamento;
- Dicionário de dados;
- Documentação das tabelas;
- Documentação dos relacionamentos;
- Regras relacionadas aos dados.

## Principais entidades

Entre as entidades inicialmente previstas estão:

- Usuário;
- Cliente;
- Prestador;
- Serviço;
- Categoria;
- Habilidade;
- Solicitação;
- Proposta;
- Agendamento;
- Avaliação;
- Mensagem;
- Notificação;
- Denúncia.

## Dicionário de dados

Cada tabela deverá possuir documentação contendo:

- Nome;
- Descrição;
- Campos;
- Tipos;
- Chaves;
- Relacionamentos;
- Restrições.

## Objetivo

Garantir que a estrutura de dados esteja documentada e alinhada aos requisitos e regras de negócio da aplicação.
