# Casos de Uso

## Descrição

Esta pasta contém a documentação dos casos de uso do Conecta Marketplace.

Os casos de uso descrevem como os diferentes usuários interagem com o sistema para alcançar determinados objetivos.

## Principais atores

### Cliente

Utiliza a plataforma para procurar e contratar serviços.

### Prestador

Utiliza a plataforma para divulgar suas habilidades e realizar serviços.

### Administrador

Responsável pela administração, moderação e gerenciamento da plataforma.

- UC-011 - Avaliar serviço;

## Documentação

Cada caso de uso deverá apresentar:

- Identificação;
- Nome;
- Ator;
- Objetivo;
- Pré-condições;
- Fluxo principal;
- Fluxos alternativos;
- Pós-condições;
- Regras de negócio relacionadas.

## Objetivo

Documentar claramente as interações entre os usuários e o sistema.
